## 構成
| 時間 | 内容 |
|---|---|
| 0〜2.1s | **サムネ兼つかみ**：「“見る専”の女の子へ／推し活のお金 自分で稼げたら？」 |
| 2.1〜27.3s | 本編：言い直しと沈黙をすべてカット、カットごとに寄り／引きを交互にして切れ目を目立たなくした |
| 27.3〜29.1s | 締め：「気になったら DMまってます／話を聞くだけでもOK」 |

- ピコーン（ひらめき効果音）は決め台詞の4か所だけ：稼ぐ側に／主人公に／全部自分の力で／一番輝く
  （同時に大きな文字の演出とズームパンチ）
- テロップのキーワードはピンク・イエローで強調
- BGMは声が出ている間だけ自動で音量を下げる（ダッキング）、全体の音量は -14 LUFS
